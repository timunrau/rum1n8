Frequently
asked questions

Do I need to install anything?

No. You can use Ruminate directly in your browser or install it from Google Play.

Can I import my existing verses?

Yes. Import verses from a CSV file, including verses from other Bible memory apps.

Can I use Ruminate on multiple devices?

Yes. Export and import your verses, or set up optional sync using your own storage.
