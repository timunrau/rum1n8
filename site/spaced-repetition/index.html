How spaced repetition works

Recalling something from memory, with time between attempts, helps it stay in memory longer. This combines two well-studied learning methods: active recall and spaced repetition.1, 2

Memory fades between reviews

After something is learned, the ability to recall it tends to decline quickly at first, then more slowly. This pattern is called the forgetting curve.3 The lower the line falls, the less likely the information is to come to mind.

A review lifts and flattens the curve

Recalling a verse without looking at the words is active recall, also called retrieval practice. Checking the text afterward provides a chance to catch and correct mistakes.

A review brings recall back up. Successful retrieval can also strengthen the memory, so the next curve falls more slowly. The memory lasts longer.1

Stronger memories can wait longer

Repeating this process over time is spaced repetition. As successful reviews make a memory more durable, the gaps between reviews can grow.

Why leave a gap?

A recently practiced verse may be easy to recall. After a gap, bringing it to mind takes more effort. Successful recall that takes some effort can improve long-term retention more than easier repetitions.4

The aim is to allow some fading while recall is still possible. Waiting longer is not always better.2 When recall fails, checking the words and practicing again helps restore the memory. A shorter gap before the next review may help.

A daily practice can include different verses each day. Verses due for review get attention while familiar ones have more time between attempts.

Sources

  2. Cepeda et al. (2008). Spacing and the timing of reviews.
  3. Murre & Dros (2015). Ebbinghaus’ forgetting curve.
  4. Pyc & Rawson (2009). Effortful, successful retrieval.
